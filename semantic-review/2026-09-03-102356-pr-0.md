## Inclusive cutoff and deterministic expired settlement

On September 2, August 18 00:00 IST is accepted by pending and manual-action queries, while only earlier dates expire. Its serialized deadline is September 2 23:59:59.999 IST.

Cron now settles `pending`, `none`, and null before selecting remaining `none`/null rows for free quota. The list endpoint uses the same unresolved set and finite-positive multiplier normalization, eliminating the prior order-dependent `auto_paid` versus Unexcused Unpaid result.

## Face transition, cancellation, and source invariants

An open session selects Face Out; closing it makes Face In available and the backend appends the next session, preserving IN/OUT/IN/OUT. State is refreshed around verification, while backend validation rejects an action incompatible with the last session.

Unmount marks recognition inactive, clears scan and success timers, and post-detection and pre-callback guards prevent a punch after cancellation. Current face callers send boolean `true`, manual callers send `false`, and both backend routes map those values to `face` and `manual` consistently.

## Nullable DealerInvoice matching

Invoice, dealer, customer, and sales-order values are normalized before matching, including populated-object fallbacks. Dropdown option arrays and candidate fields are guarded, and drafts contribute `DRAFT` when the invoice number is absent.
